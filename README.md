Entry for the make.fun competition **news-image-20261118**: sum up 18 November's
world news in one image. A dense front page — 35 stories, 6 continents, one page.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies the finished image to `/output/entry.png` (JPEG bytes are
accepted at that path per the competition rules).
